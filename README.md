# Bird Flying SolidWorks

A SolidWorks-based mechanical bird flying model project containing assembly files, a spur gear assembly, preview screenshots, and a motion video.

## Repository Contents

- `Bird Mechanism Final Assembly.SLDASM` — main bird mechanism assembly.
- `Spur Gear.SLDASM` — spur gear assembly used in the mechanism.
- `Bird_flying.mp4` — animation/video preview of the mechanism in motion.

## Requirements

- SOLIDWORKS (version compatible with the provided `.SLDASM` files)

## How to Use

1. Clone or download this repository.
2. Open `Bird Mechanism Final Assembly.SLDASM` in SOLIDWORKS.
3. Open `Spur Gear.SLDASM` if you want to inspect the gear subsystem separately.
4. Use SOLIDWORKS Motion/Assembly tools to review mates and mechanism movement.
5. Watch `Bird_flying.mp4` for a quick preview.

## Notes

- If assembly references are missing on open, use SOLIDWORKS file reference tools and keep all repository files in one directory.
- This repository primarily stores design assets (not source code).
